# Cybersecurity Threat Intelligence

## Project Overview
A cybersecurity analytics dashboard developed using Microsoft Power BI to visualize security-related data and support threat monitoring.

## Tools
Microsoft Power BI, Data Transformation, Data Visualization.

## Analysis Focus
- Threat distribution
- Security incident trends
- Threat categories
- Risk and severity indicators

## Project Goal
Present cybersecurity data in a clear and interactive format to support monitoring and analytical reporting.
